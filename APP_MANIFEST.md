# NEO Engine — App File Manifest

**Purpose:** identify the files the *running* ML engine actually depends on, so they
can be told apart from the hundreds of old experiments / scratch versions in this
directory. **Nothing here has been moved** — moving files would break the systemd
service (`neo-engine.service`), whose unit pins:

```
WorkingDirectory=/root/Project/ML
ExecStart=/root/venv/bin/python /root/Project/ML/main4.py
StandardOutput=append:/root/Project/ML/logs/engine.log
```

Generated by an automated audit pass. Runtime import chain traced from `main4.py`.
